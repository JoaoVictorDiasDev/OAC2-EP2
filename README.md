### English
- This repository hosts a college project featuring parallel implementations of QuickSort and Selection Sort in C, designed to improve the efficiency of sorting operations by utilizing concurrent processing techniques. The project was developed as part of a university course assignment and demonstrates key principles of parallel computing and algorithm optimization with input datasets provided in the accompanying directory.

- To compile and run the project, clone the repository and use a C compiler with OpenMP (or POSIX threads) support. For example, compile with gcc -fopenmp main.c -o parallel_sort and then execute the resulting program with ./parallel_sort. This approach enables students to explore the challenges and benefits of parallel programming in a practical academic context.

### Português
- Este repositório abriga um projeto universitário que apresenta implementações paralelas dos algoritmos QuickSort e Selection Sort em C, com o objetivo de melhorar a eficiência das operações de ordenação por meio do processamento concorrente. O projeto foi desenvolvido como parte de uma disciplina acadêmica, demonstrando os princípios fundamentais de computação paralela e otimização de algoritmos, com conjuntos de dados disponíveis na pasta de apoio.

- Para compilar e executar o projeto, clone o repositório e utilize um compilador de C com suporte a OpenMP (ou threads POSIX). Por exemplo, compile com gcc -fopenmp main.c -o parallel_sort e execute o programa gerado com ./parallel_sort. Este método permite aos estudantes explorar, na prática, os desafios e as vantagens da programação paralela em um contexto acadêmico.
